## 🎯 Project Overview & Key Insights

This dashboard provides business leaders with an intuitive overview of store performance across various regions, product categories, and shipping modes.

### 🔑 Key Performance Indicators (KPIs - 2018):
* **Total Orders:** 969 orders
* **Total Sales:** $484.25K
* **Total Profit:** $49.54K
* **Average Discount:** 16%
* **Total Quantity Sold:** 7,581 units

---

## 📈 Visualizations Breakdown

1. **Regional & Category Breakdown:**
   * **Orders by Region:** Highlights distribution across West, East, Central, and South regions (West leading with 313 orders).
   * **Orders by Category:** Displays proportion of sales across *Office Supplies (54%)*, *Furniture (25%)*, and *Technology (21%)*.
   * **Top 5 Sub-Categories:** Binders (258), Paper (236), Furnishings (168), Storage (163), and Art (152).

2. **Trends & Financial Analysis:**
   * **Profit by Date (Monthly Trend):** Line chart showcasing month-over-month profit fluctuations throughout 2018.
   * **Waterfall Analysis (Profit & Discount by Ship Mode):** Analyzes total profit generated by *Standard Class*, *Second Class*, *First Class*, and *Same Day* shipping methods.

3. **Geographical Insights:**
   * **US Map Visualization:** Filled map depicting order intensity by state.
   * **Tree Map:** Proportional representation of order volumes across all US states (e.g., California, New York, Texas).

4. **Tabular Details Page:**
   * Granular table breaking down category, sub-category, region, year, month, total sales, and sum of profit.

---

## 🛠️ Built With

* **Tool:** Power BI Desktop
* **Data Sources:** Superstore Dataset (Excel / CSV)
* **Visualizations Used:** Bar Charts, Donut Chart, Funnel/Horizontal Bar Chart, Line Chart, Waterfall Chart, Filled Map, Tree Map, and Interactive Table Cards.
* **DAX & Modeling:** Measures created for Total Sales, Total Profit, Order Count, and Average Discount.

---

## 🚀 How to View the Dashboard

1. Download the `.pbix` file from this repository.
2. Open it using **Power BI Desktop**.
3. (Optional) Make sure to update data source paths if re-linking the dataset.
